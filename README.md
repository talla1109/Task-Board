# To-Do List (DCIT 26 Laboratory 2)

React + Tailwind CSS to-do list. Add, complete (Done / Not Done), delete, clear done, and reset tasks.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy (Vercel)
1. Push this folder to a GitHub repository.
2. On vercel.com choose Add New > Project and import the repository.
3. Keep the detected Vite settings (Build: `npm run build`, Output: `dist`) and press Deploy.
4. Submit the generated URL, e.g. https://talla-todo-list.vercel.app
